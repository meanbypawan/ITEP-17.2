JWT Security

Protect every endpoint except

Signup
Login
Swagger

Use JWT authentication for all other routes.

Business Rules
Signup
Email must be unique.
Password must contain at least 6 characters.
Login
Validate email and password.
Return JWT token.
Create Post
Only authenticated users can create posts.
Update/Delete Post
Only the owner can modify or delete the post.
Like
One user can like a post only once.
Comment
Only the owner can edit or delete their comment.
